URL 만으로 쓰는 커스텀 목 데이터
프리셋
처음이신가요? 실제 API 응답 JSON 을 붙여넣기만 하면 목 API 가 만들어지고, 아래 필드를 고치면 URL 과 미리보기가 실시간으로 바뀝니다.

스키마

/api/
필드명이 응답 JSON 의 key 가 됩니다 · 점(.)으로 중첩: customer.name → {"customer":{"name":…}} · 배열은 이름 뒤 []: tags[]

옵션

타입 칸에 입력하면 자동완성 목록이 뜹니다 · 중첩: address.city · 배열: tags[] · 자세한 건 사용법 · 전체 타입: /schema/types

사용법

1시작은 둘 중 하나

JSON 붙여넣기 — 실제 API 응답을 그대로 붙여넣으면 필드와 타입이 자동으로 채워집니다. 가장 빠른 방법.
프리셋 — 상단 사용자/상품/주문 버튼으로 시작해서 고치기.

2필드 = 이름 + 타입

왼쪽 칸이 JSON 의 key, 오른쪽 칸이 그 값을 만드는 방법(타입)입니다. 타입 칸에 글자를 입력하면 자동완성 목록이 뜹니다. 예를 들어 per 만 쳐도 person 계열이 나옵니다.

만들고 싶은 값타입결과 예

도시 / 주소 / 회사location.city location.streetAddress company.name"서울" / "…로 12" / "주식회사 …"
범위 안의 숫자int:20~60 · float:0~100:234 · 87.52

3객체 안에 객체 — 이름에 점(.)

필드명에 점을 찍으면 중첩 객체가 됩니다. 타입은 평범하게 쓰면 됩니다.

customer.name          =  person.fullName
customer.address.city  =  location.city
↓ 이렇게 응답됩니다
{ "customer": { "name": "김민준", "address": { "city": "서울" } } }

4배열 — 이름 뒤에 [], 개수는 값 끝에 :N

tags[]  =  lorem.word:3   →   "tags": ["가방", "나무", "다리"]

✓알아두면 좋은 것

같은 URL 은 항상 같은 데이터를 돌려줍니다 — 새로고침해도, 내일 다시 열어도 동일합니다. 스냅샷 테스트에 안전합니다.
다른 데이터셋이 필요하면 _seed=아무값 을 붙이세요.
URL 을 잘못 쓰면 400 응답이 무엇이 왜 틀렸는지 알려줍니다.

JSON 붙여넣기

실제 API 응답이나 예시 객체를 붙여넣으면 필드와 타입을 자동으로 추론합니다. {"data": [...]} 같은 envelope 도 알아서 벗겨냅니다.
