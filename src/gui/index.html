피드백

    

    
불편한 점, 갖고 싶은 기능 — 무엇이든 좋아요. 익명으로 개발자에게 전달됩니다.

    
    

    

      
      
    

  






  

    

      
      
사용법

    

    

      
1시작은 둘 중 하나

      
JSON 붙여넣기 — 실제 API 응답을 그대로 붙여넣으면 필드와 타입이 자동으로 채워집니다. 가장 빠른 방법.

         프리셋 — 사용자/상품/주문 프리셋으로 시작해서 고치기 (데스크톱은 상단 버튼, 모바일은 드롭다운).


      
2필드 = 이름 + 타입

      
왼쪽 칸이 JSON 의 key, 오른쪽 칸이 그 값을 만드는 방법(타입)입니다.
         타입 칸에 글자를 입력하면 자동완성 목록이 뜹니다. 예를 들어 per 만 쳐도 person 계열이 나옵니다.

      

        
만들고 싶은 값타입결과 예

        
이름 / 이메일 / 전화person.fullName internet.email phone.number"김민준" / "mia.kim@example.com" / "010-…"

        
도시 / 주소 / 회사location.city location.streetAddress company.name"서울" / "…로 12" / "주식회사 …"

        
범위 안의 숫자int:20~60 · float:0~100:234 · 87.52

        
참/거짓 (확률 지정)bool:0.880% 확률로 true

        
몇 개 중 하나enum:pending|paid|shipped셋 중 하나

        
기간 안의 날짜date:2024-01-01~2026-12-31"2025-06-01T09:12:00.000Z"

        
항상 같은 값const:v1"v1"

        
고유 ID / 순번uuid · index"a1b2…" · 0, 1, 2…

        
긴 글 / 이미지text:50 · image:200x20050자 문장 · 이미지 URL

      

      

        고급 타입 — 더 현실적인 데이터가 필요할 때
        

          
만들고 싶은 값타입결과 예

          
포맷 있는 코드pattern:ORD-####-???"ORD-4821-KQZ" — #숫자 ?대문자 *영숫자

          
확률이 다른 택1enum:paid*8|refund*2paid 80% / refund 20%

          
가끔 nullinternet.email?0.220% 확률 null — 모든 타입 뒤에 ?확률

          
가려진 개인정보mask.name mask.email mask.phone mask.card"김*준" / "mi***@example.com" / "010-****-5678"

        

      


      
3객체 안에 객체 — 이름에 점(.)

      
필드명에 점을 찍으면 중첩 객체가 됩니다. 타입은 평범하게 쓰면 됩니다.

      
customer.name = person.fullName
customer.address.city = location.city

      
↓ 이렇게 응답됩니다

      
{
  "customer": {
    "name": "김민준",
    "address": { "city": "서울" }
  }
}


      
4배열 — 이름 뒤에 [], 개수는 값 끝에 :N

      
tags[] = lorem.word:3

→ "tags": ["보장하기", "재외국민을", "영장을"]


      
5페이지네이션과 테스트 옵션

      

        
옵션용도

        
_total / _limit / _page가상 전체 개수 / 페이지당 개수 / 페이지 번호

        
_delay=30003초 늦게 응답 — 로딩 스피너 테스트

        
_status=500상태코드 강제 — 400 이상이면 데이터 대신 실패 바디가 나갑니다 (아래 6번)

        
_method=post손으로 URL 을 쓸 때 메서드 지정 — GUI 버튼을 쓰면 안 붙습니다 (아래 6번)

        
_body={"code":"E_AUTH"}실패 응답 바디를 직접 — _status 가 400 이상일 때만

        
_locale=en영어 데이터 (ja 일본어, zh 중국어)

        
_seed=v2다른 데이터셋 — 시드가 같으면 데이터도 항상 같습니다

        
_wrap=noneenvelope 없이 배열만 (one 은 단일 객체 — 상세 API)

        
_format=ndjson아이템만 줄 단위 스트리밍 — 대용량 (csv 도 가능)

        
_q=김생성 데이터 검색 — 값 부분일치, total 은 매치 수

        
_qin=name,city검색 대상 필드 한정 — _q 와 함께 (중첩은 a.b)

        
_alias=page:_page예약 키를 실제 API 이름으로 — 옵션의 키 이름을 직접 클릭해 바꾸면 자동 생성됩니다

      

      
상한: _limit 최대 1000 · _q 100자 · _delay 5초.
         더 많은 데이터는 _page 로 이어 받으세요 — 예: 5,000개는 _total=5000&_limit=1000 으로 5페이지.


      
6GET 말고 POST·PUT·PATCH·DELETE

      
생성된 URL 위의 버튼으로 메서드를 고르면 그 메서드로 실제 요청을 보냅니다.
         URL 자체는 메서드와 무관하게 깨끗합니다 — 메서드는 여러분 코드의 fetch(url, { method: 'POST' }) 가 정합니다.

      

        
메서드상태응답

        
GET200목록 (_wrap 에 따라)

        
POST201생성된 단건

        
PUT / PATCH200수정된 단건

        
DELETE204본문 없음

      

      
돌려주는 단건은 같은 스키마 GET 목록의 첫 아이템과 완전히 같습니다 —
         메서드는 모양만 바꾸고 데이터는 건드리지 않습니다. 요청 바디는 보지 않습니다.


      
7실패 응답 만들기

      
상태코드를 400 이상으로 두면 데이터 대신 실패 바디가 나갑니다.
         표준 4xx·5xx 는 전부 제 이름을 갖습니다 (404 → Not Found, 413 → Payload Too Large).

      
{ "error": "Not Found", "status": 404, "message": "요청을 처리하지 못했습니다." }

      
직접 쓰고 싶으면 고급의 실패 바디 칸에 JSON 을 넣으세요. 칸이 비어 있으면
         기본 응답이 회색으로 미리 보이고, Tab 을 누르면 그대로 채워집니다 — 거기서 고쳐 쓰면 됩니다.
         붙여넣은 JSON 은 자동 정렬되고, 직접 친 건 { } 정렬 버튼으로 맞춥니다.


      
✓알아두면 좋은 것

      
같은 URL 은 항상 같은 데이터를 돌려줍니다 — 새로고침해도, 내일 다시 열어도 동일합니다. 스냅샷 테스트에 안전합니다.

         다른 데이터셋이 필요하면 _seed=아무값 을 붙이세요.

         완성된 스키마는 저장 버튼으로 팀과 공유하세요 — ?_s=ID 짧은 URL 이 생기고, 다른 파라미터로 덮어쓸 수 있습니다 (예: ?_s=aB3xK9&_page=2). TS 타입 복사 버튼은 지금 스키마의 TypeScript 인터페이스를 바로 만들어 줍니다.

         URL 을 잘못 쓰면 400 응답이 무엇이 왜 틀렸는지 알려줍니다.

         리소스 경로는 /api/v2/users/123/orders 처럼 여러 단계도 됩니다 — 경로는 장식이고 데이터는 쿼리로 결정되며,
         상세 응답은 _wrap=one&_seed=123 조합으로 만듭니다.

    

    

      
    

  






  

    

      
      
워크스페이스

    

    
프리셋 저장·공유는 워크스페이스 단위로 이뤄지고, 링크를 아는 사람만 접근할 수 있습니다.

    

    

      
      
      
    

    

      
      
    

    

    

      링크를 잃어버리면 워크스페이스를 다시 찾을 수 없어요 — 팀 문서에 보관하세요. 저장물은 180일 미사용 시 만료됩니다.

    

      
    

  






  

    

      
      
프리셋으로 저장

    

    
워크스페이스의 프리셋 목록에 추가되고 짧은 URL 이 생깁니다.

       내용을 고쳐 다시 저장하면 새 URL — 기존 URL 은 그대로 유지돼요.

    

      
팀 저장이 아직 활성화되지 않았습니다.

      저장소(Cloudflare KV)를 한 번만 연결하면 됩니다 — 배포 담당자가 터미널에서:

      
npx wrangler kv namespace create SCHEMAS
# 출력된 id 를 wrangler.toml 의 [[kv_namespaces]] 블록에 붙여넣고 주석 해제
npm run deploy

      
연결 전에도 다른 기능은 전부 정상 동작합니다.

    

    

      
프리셋 저장에는 워크스페이스가 필요합니다.

      링크를 아는 사람끼리만 공유돼요.

JSON 붙여넣기

    

    
실제 API 응답이나 예시 객체를 붙여넣으면 필드와 타입을 자동으로 추론합니다.
       {"data": [...]} 같은 envelope 도 알아서 벗겨냅니다.
